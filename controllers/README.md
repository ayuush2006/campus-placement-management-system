# Controllers Directory

Controllers contain the core logic for handling incoming requests and sending back responses.

Examples of upcoming files:
- `authController.js`: Handles student and admin registration/login.
- `studentController.js`: Handles student profile, applying for jobs, viewing applications.
- `jobController.js`: Handles job listings, eligibility evaluation.
- `adminController.js`: Handles job posting, viewing applicants, shortlisting/rejecting.
