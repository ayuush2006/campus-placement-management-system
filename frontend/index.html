Phase 3 Implemented REST APIs

  • POST /api/students - Register student with profile
  • GET /api/students/:id - Get student details by ID
  • PUT /api/students/:id - Update student profile details
  • GET /api/companies - Get all participating companies
  • POST /api/companies - Create a new company record
  • PUT /api/companies/:id - Update company details
  • DELETE /api/companies/:id - Delete company safely
  • GET /api/jobs - Get all job openings with company joins
  • GET /api/jobs/:id - Get single job details by ID
  • POST /api/jobs - Post new job with eligibility criteria
  • PUT /api/jobs/:id - Update job opening details
  • DELETE /api/jobs/:id - Delete job opening
  • POST /api/applications - Submit job application
  • GET /api/applications/student/:studentId - Student application status
  • GET /api/applications/job/:jobId - Job applicant listings
