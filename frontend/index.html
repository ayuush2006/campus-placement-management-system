Phase 2 Relational Database Schema

The system uses MySQL with 5 relational tables:

  • Table users - Stores student and admin credentials & roles
  • Table student_profiles - Academic data (CGPA, Branch, Backlogs) [FK: user_id]
  • Table companies - Company profiles and recruiting contacts
  • Table jobs - Job openings with eligibility criteria [FK: company_id]
  • Table applications - Student applications & statuses [FKs: student_id, job_id]
