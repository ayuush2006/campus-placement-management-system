# Routes Directory

Routes define the API URL endpoints and link them to their corresponding controller functions.

Examples of upcoming files:
- `authRoutes.js`: Endpoints for login and registration (`/api/auth`).
- `studentRoutes.js`: Endpoints for student actions (`/api/student`).
- `jobRoutes.js`: Endpoints for job listings (`/api/jobs`).
- `adminRoutes.js`: Endpoints for administrative tasks (`/api/admin`).
